IP address: An IP address is a unique label assigned to a device connected to a network.
Network ID / Host ID: The network ID identifies the network, while the host ID identifies the device on that network.
Subnet: A subnet is a smaller part of a network; it creates a boundary that helps organize and control network traffic.
Router: A router's job is to send data between different networks.
Default gateway: The default gateway is the router that a device uses to send data outside its own network.
DNS: DNS converts a website name into an IP address because computers use IP addresses to find the destination.
Port: A port identifies the specific service or application to send data to on a device, like different doors leading to different rooms.
HTTP vs HTTPS: They both transfer web data, but HTTPS uses TLS encryption to protect the data while it travels across the network.
NAT: NAT allows many devices with private IP addresses to share one public IP address when accessing the internet.
